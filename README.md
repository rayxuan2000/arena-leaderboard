# AI Arena Leaderboard

[![Update Leaderboard & Deploy](../../actions/workflows/deploy.yml/badge.svg)](../../actions/workflows/deploy.yml)

一个**全维度 AI 模型能力排行榜**网站：把 [arena.ai](https://arena.ai) 上分散的各类榜单（对话、代码、视觉、文生图、文生视频……）汇总成一个统一、好读的网页，**每天自动更新**，并同时生成一份可下载的 Excel 表格。

> 数据来自 arena.ai 的公开榜单，每天清晨自动同步一次，无需人工干预。
>
> 排名基于 arena.ai 的**真人盲测投票**（Bradley-Terry/Elo），衡量的是**人类偏好**而非绝对能力或正确性；适合横向参考与趋势观察，选型仍建议结合自身任务实测。网页顶部「关于本榜单」卡片有更详细的生成逻辑与优缺点说明。

## 网页上能看到什么

- **各类别完整排名**：模型名称、所属厂商、是否开源等，一目了然。
- **能力分数横向柱状图**：每个模型的 Elo 分数以横向柱呈现，柱长直观反映高低（以该榜最低分为基线放大差异）。Agent 榜则把「净提升」画成柱状图。
- **置信区间放大标尺**：柱状图右侧有一个独立小标尺，专门显示 95% 置信区间。它**按本榜的置信区间量级单独缩放**，所以即使基数分数很大（如 1500）、置信区间很小（如 ±4），也能清晰看出区间宽窄并横向比较，不会挤成一条线。中心圆点是估计值，左右须代表上下限。
- **柱色按国别区分**：国外模型用蓝色柱、国内（中国）模型用红色柱，工具栏右侧有图例。分类表外置在 `data/regions.json`，**每日榜单更新若出现新厂商，构建会自动告警并把未识别厂商写入 `data/regions_unclassified.json`**，在 `regions.json` 里补一行即可（无需改代码）；未识别的厂商柱子显示为灰色「未分类」，不会被误涂成国内/国外。
- **悬浮看详情**：鼠标移到柱状图上，弹出详情卡显示投票数、排名区间、价格、上下文长度（Agent 榜显示各行为指标与会话数）。
- **即时搜索 / 点击排序 / Tab 直达**：搜索框按模型名或厂商即时过滤；点击列头升序→降序→还原三态排序；当前 Tab 记入网址锚点，可刷新保持、复制分享。
- **冠亚季军区分**：每个榜单前三名整行以金 / 银 / 铜底色高亮；模型是否开源用文字颜色区分。
- **厂商图标**：每个模型名前显示对应产品的小图标，方便快速辨认出自哪家。
- **智能体（Agent）榜专属指标**：把鼠标移到列标题的 ⓘ 上即可看到各行为指标的中文解释。
- **汇总总览页**：一页速览每个类别的冠亚季军。
- **可下载 Excel**：同一份数据还会生成带格式的 Excel 表格供下载。

## 数据多久更新一次

网站托管在 GitHub 上，**每天北京时间清晨（约 06:23，对应 UTC 22:23）自动运行一次**：抓取 arena.ai 最新数据 →（兜底渲染）→ **数据健全性校验** → 重新生成网页和 Excel → 发布上线。也可以在 GitHub 页面手动点一下立即更新。

> GitHub 的定时任务是「尽力执行」，高峰期（尤其 UTC 整点和 UTC 午夜前后）会被排队延迟，偶尔可达一两小时，属正常现象。因此这里特意选了 UTC 22:23 这个非整点、远离午夜洪峰的时段，并预留缓冲——即便有所漂移，也能在北京早晨上班前完成刷新。页面页脚显示的是**实际执行时间**，所以看到的不一定恰好是 06:23。

**抓取的稳健性设计**（避免某天官网抽风就把线上榜单搞坏）：

- **兜底渲染**：直连 arena.ai 解析失败时，自动用 `--allow-jina` 经 Jina Reader 再渲染一次重试。
- **解析到 0 行不覆盖**：某榜单抓空时保留上一版好数据，且 `fetch_arena.py` 会以非零退出码让本次运行失败报警。
- **数据校验守门**（`scripts/validate_data.py`，抓取后、构建前运行）：对比上一版已提交数据，若某榜单**断崖式暴跌**（疑似官网改版只解析出几行）或核心榜单过少、总数过低，则**中止构建与部署**——线上保持上一版好数据，并通过 GitHub 的失败通知提醒你。

> 一句话：数据正常时全自动更新；数据异常时宁可不更新、也不会把坏榜单推上线。

## 如何访问 / 启用

- **查看网站**：部署完成后，打开 GitHub Pages 给出的网址即可（形如 `https://<用户名>.github.io/<仓库名>/`）。
- **首次启用**：在仓库 **Settings → Pages → Source** 处选择 **GitHub Actions**，即可开始自动发布。

## 本地运行（可选，面向开发者）

想在自己电脑上跑一遍：

```bash
pip install -r requirements.txt
python scripts/fetch_arena.py --out-dir data --allow-jina   # 抓取最新数据（含兜底）
python scripts/validate_data.py --data-dir data             # 数据健全性校验
python scripts/export_arena_excel.py                        # 生成 Excel
python build_site.py                                        # 生成网页 index.html
```

## 数据来源与声明

本项目仅抓取并展示 [arena.ai](https://arena.ai) **公开发布**的榜单数据，用于个人学习与可视化展示。榜单数据版权归 arena.ai 所有；本项目为非官方工具，与 Arena 官方无任何关联。网页中的厂商图标在构建时获取（优先取自 arena.ai 自带的品牌图标，其次为厂商官网）并内嵌进网页，仅用于标识对应厂商/产品；浏览时不发起任何第三方请求，因此在各网络环境下显示一致。
